## 如何使用本账本

每个稳定 ID 对应一项验收主张。`U` 表示 3.0 未验证；只有证据记录包含被测提交与产物、来源版本或冻结 fixture、准确调用、实际结果及剩余限制，才可更改状态。`P` 表示整项通过，`F` 表示失败，`B` 表示所需来源或环境不可用。若一项主张后来包含可独立验收的结果，应拆分 ID；局部成功不能关闭整行。链接文档中的历史观察沿用各自原有的日期和范围。Fixture 只证明它覆盖的形状；现行格式支持还须按[贡献 Provider 指南](../CONTRIBUTING-PROVIDER.md#provider-evidence-freshness)重新核对上游与真实来源。

`U` 不表示没有实现：五 provider 的基础读取、部分 Reader／Runtime、六个既有 MCP 工具及原生团队消息工具和 Windows 便携候选已有可运行切片与测试。各切片的 RED／GREEN、被测 binary、真实来源及剩余条件记录在[交付计划的进度记录](agentsession-v3-delivery-plan.md#进度决策与恢复记录)。本账本只在整行目标和验证方法都满足时改变状态。

下表的“3.0目标”规定每行要求；证据列记录已取得结果、准确归属和剩余缺口，状态列给出当前整项结论。“验证方法”列指向可移植测试或具体比较过程；只有实际执行记录能证明一次验证已完成。Provider 拥有的记录只读；提交的验收产物不保存会话原文；记录中区分 `recorded`、`derived`、`unsupported`、`unavailable` 与 `invalid`。
