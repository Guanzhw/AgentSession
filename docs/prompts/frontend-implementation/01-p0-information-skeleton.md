# 前端实现 · P0:信息骨架(导航 + 详情页壳 + 卡片字段)

```text
P0 目标:搭起 UI v2 的信息骨架,让"该有的信息都在、层级按设计",视觉朴素。

范围(对应 docs/design/ui-v2.md §2/§3/§4.1/§4.2/§5):
1. 顶层导航:库 / 统计 / 设置 三页(rail);旧顶栏双 Tab 与旧导航模型废弃;
2. 详情页:头部(标题/provider/项目路径/开始时间/文件改动 +N−N/操作:在终端中继续、
   星标、导出 MD/JSON、在对话中查找、返回、上一条/下一条/恢复命令一行等宽)+
   三标签壳:工作(默认)/ 对话 / 事件;
3. 库列表卡片字段齐:标题、provider、相对时间、项目路径、消息数、tokens、时长、
   压缩 ×N、子代理 N、artifacts N(三个信号合并为一行"信号条",见 §11 开放问题3);
4. 默认不显示清单落地:协议版本号、覆盖状态、原始实体 ID 不进主视觉;
5. highlight.js 改为本地 vendored(去掉 CDN,恢复离线完整性);
6. 空态/加载/错误/存储诊断四类状态文案,双 locale 一次到位。

边界:本阶段不实现线程化、叙事化、事件页完整内容——先把壳与信息层级做对。
验收:仅移除“已被替代结构且无现存消费者”的旧 CSS 选择器与 data-* 钩子
(以 grep 无引用为准,app.js 选择器同步重命名),保留主题变量、语义样式、
可访问性与无关行为;三页 + 三标签可导航(默认工作);真实会话详情页头部信息完整;
键盘 1–3 导航;npm test + 双 locale + 320/768/1280 三档。
完成动作:为 UI v2 实现建 implemented 决策记录(蓝图=docs/design/ui-v2.md,
记录分层替换策略与验证结果)。
```
