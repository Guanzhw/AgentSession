# 前端实现 · P1:库页(搜索/筛选/时间轴/批量)

```text
P1 目标:库页按 §4.1 实现,过滤状态进 URL 可回退。

范围:
1. 统计条(提供方/会话/消息/Token,来自启动索引一次查询);
2. 搜索:跨 provider 的主搜索沿用启动索引,覆盖标题/自定义标题/项目路径;
   provider 内已有的内容搜索入口继续保留。索引尚无模型或消息内容字段,本阶段不伪装支持;
3. 筛选 chips:时间(今天/本周)、星标、有子代理;其余进"高级筛选";
4. 时间轴(默认,按天分桶)与紧凑列表一键切换,偏好入 localStorage;
5. 批量管理(星标/删除,有确认);无限滚动保留;
6. 存储诊断置顶一行、不打断列表;空库/无结果态说人话。

边界:provider 多选沿用现有 query 参数机制;不做新的搜索后端。模型与跨 provider
内容搜索属于后续索引契约议题,需先有真实消费者与成本证据。
验收:真实数据按 provider/时间/星标过滤正确;URL 刷新/回退不丢状态;
批量操作有反馈与确认;qa:e2e 断言随新结构更新(库页部分)。
```
