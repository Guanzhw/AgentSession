# 前端实现 · P3:工作叙事化

```text
P3 目标:工作页从罗列改为叙事(§2 痛点1、§4.4、§4.7 场景 3/4)。

范围:
1. 阅读顺序:目标叙事(标题+描述+状态)→ 进度一句话(任务状态派生,呈现层文案,
   不进协议数据)→ 结构图 → 任务表(折叠)→ 交接(按需);
2. 结构图两张:任务图(目标→任务)+ agent 协作图(agent 节点,边=协作关系与通道,
   标注消息数与方向,team 分组),各自有界 ≤9 节点,窄屏降级为缩进列表(§11 开放问题4);
   异步派发用虚线边;
3. 任务表:人类可读标题(回退路径)、状态、耗时、证据按钮;超 5 条折叠为
   "还有 N 个任务…";点击任务行"在对话中定位"(切对话页并滚动到对应工具调用/agent 卡);
4. 废除:原始 relations 行罗列(由结构图+子代理列表取代);
5. 后台任务(§4.6):无子会话的后台 run 同样双锚;后台任务同时出现在任务表(工作)
   与资产区(产物),互跳;
6. 与对话页分工红线:工作页不显示对话原文,对话页不显示整体进度。

验收(§4.7 场景 3/4 走查):真实 Codex 会话一屏看懂"想做什么/做到哪了/谁在协作";
memory 后台任务可从任务表跳到资产区条目;无子会话后台进程有双锚;
协议未记录的 observation 显示"没有记录"。
```
