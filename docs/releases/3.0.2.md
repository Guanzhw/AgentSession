# AgentSession 3.0.2

本版是 3.0 的稳定补丁，修复用量统计、来源诊断和搜索结果可见性，使用 npm
`latest` 和普通 GitHub Release。

## 安装与升级

锁定版本安装：

```sh
npm install -g @acetamido/agentsession@3.0.2
npm install -g @acetamido/agentsession-mcp@3.0.2
agentsession
```

npm 入口需要 Node.js 22.15 或更新版本。预发布渠道继续使用 `next`。
从 v1.10.1 升级的端口、MCP/API 和元数据导入步骤见
[3.0.0 更新说明](3.0.0.md)与[元数据导入指南](../../v3/README.md#viewer-metadata-import)。

升级会自动刷新旧派生摘要和 Reader 缓存：摘要 schema 为 16，Reader cache
schema 为 3，projection 为 11。首次读取可能重新捕获来源；Provider 数据和
Viewer 收藏、标题、回收站状态保留。旧程序会明确拒绝较新的缓存 schema，
回退运行应使用其兼容的独立派生状态目录。

## 修复与行为

- **Codex 发现与累计 Token 统计。** 新状态下按 canonical 会话身份发现记录，兼容
  旧 `session_id` 头。普通 `token_count` 的累计增量计入已知 Token 小计，重复
  快照不重复计数；请求数继续要求明确请求身份。趋势、Harness 与模型份额默认
  按 Token 展示。
- **Claude 用量去重。** pending 记录不占用 response ID，真实用量按 response
  去重，保留已记录的 Token 分量。完全缺失 `usage` 时摘要保持未知，Protocol
  不伪造请求；混合记录保留已知合计，原消息保持可读。
- **DSH 歧义诊断。** 已知歧义会话保留为诊断行，数量保持未知，搜索报告部分
  覆盖，统计明确计入排除来源。直接读取继续报告来源错误。
- **Reader Protocol 错误。** 冷读、缓存与重启后均保留具体错误及可读正文。
  HTTP 422 `protocol_invalid` 返回最多 20 条诊断与截断标记；界面显示原因、
  诊断码和来源事件。保留缺失子历史提示。
- **MCP 安全诊断。** 原生 MCP 的安全诊断写入 stderr，wire 响应保持。
- **索引与批量元数据一致性。** 移除无调用方的非索引列表分支；批量元数据操作
  共享逐来源预检与写入路径，保留事务与部分提交语义。保留 OpenCode WAL 和
  测试夹具清理修复。
- **Linux 浏览器门槛。** Linux x64 native/release CI 必跑公开浏览器回归，锁定
  agent-browser 0.39.1，检查 Chrome 并先执行启动 smoke；缺工具、UI 依赖或浏览器
  时明确失败。独立浏览器工具需要 Node.js 24+，项目开发最低版本仍为 Node.js 22.15。
- **搜索结果可见性。** 搜索定位等待目标正文首段展开，保持匹配可见与键盘焦点。

## 验证范围

发布流程在精确 tag 上执行四平台原生构建、Web/MCP、便携包和组合 npm 安装检查，
Linux x64 必跑公开浏览器用例；全部通过后才公开产物。实际结果见
[发布工作流](https://github.com/Guanzhw/AgentSession/actions/workflows/v3-prerelease.yml)。
未发布的 `v3.0.1` 标签和其 Linux 可见性断言失败保留原始记录，见
[3.0.1 记录](3.0.1.md)。

整合前冻结的 Windows 工作树完整 `npm test` 为 Rust core 266、app 10 通过，
18 项来源探针明确忽略；Node 778 通过、50 条件跳过、0 失败，`npm run review`
通过。另有 Windows x64 与 Ubuntu WSL2 x64 各 43 项浏览器回归通过。五来源
冻结副本的 Web 检查、四源 native MCP 对照及来源保全，均仅覆盖其记录的输入
与产物。这些记录保留各自的来源和产物范围。

本地 18 项来源探针忽略与 50 项条件跳过保留其边界；完整性能、资源重复、
历史 STATE-01 写入归因及其他来源、平台门槛继续按
[交付计划](../design/agentsession-v3-delivery-plan.md)与
[稳定版账本](../specs/stable-readiness-2026-10/tasks.md)追踪。历史验证不据此
证明完整性能提升。
